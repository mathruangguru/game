🧠 Game Memori & Logika

Informasi Pembelajaran

1. Tujuan: Melatih working memory, pemahaman nilai tempat (pengurutan), dan strategi berhitung mental.

2. Konsep: Number Sense, Ascending Order, dan Penjumlahan.

3. Jenjang: SD Kelas 3 - 6.

4. Cara Bermain: 3 angka awal akan muncul, lalu bertambah satu per satu tiap 3 detik. Waktu menghafal akan terus berjalan! Setelah semuanya hilang, masukkan angka dari yang terkecil ke terbesar dan hitung jumlah totalnya.
